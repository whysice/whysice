### 🧊 Whysice

Veterinary tools for owners and clinicians. Four surfaces, one brand. Inspired by Icy, born December 27.

- 📚 [**Derm Wiki**](https://whysice.netlify.app/wiki): Evidence-based canine dermatology with plain-language and clinical layers in one article
- 💊 [**Vet Med Lookup**](https://whysice.netlify.app/vetmed): 115-drug cross-specialty reference covering dosing, safety flags, and species contraindications
- 🪪 [**Whysice ID**](https://whysice.netlify.app/id): Portable universal animal ID. Same record, species-aware chart
- 📈 [**Health Tracker**](https://whysice.netlify.app/dashboard): Symptom log, treatment timeline, and vet-prep export
